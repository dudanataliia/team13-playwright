# TC-04 — Upload Image validation (PNG/JPG, max 10MB)

**Description:** Verify the validation of the "Upload Image" field (accepted formats: PNG/JPG, maximum size: 10MB).

**Preconditions:**

- The user is logged into the system.
- The "Create News" form is open.

**Steps:**

1. Navigate to [GreenCity News](https://www.greencity.cx.ua/#/greenCity/news) and click "Create News".
2. In the "Add Image" field, upload a PNG file (size: 5MB).
3. Verify that the image uploads successfully without errors.
4. Upload a GIF file (size: 1MB).
5. Verify that the field is highlighted in red with an error message: "Upload only PNG or JPEG. File size must be less than 10MB."
6. Upload a JPEG file (size: 15MB).
7. Verify that the field is highlighted in red with the same error message.

**Expected Result:**

- Only PNG and JPEG files up to 10MB are accepted.
- Other formats or sizes cause the field to be highlighted in red with a warning message.

**Automated Verification:**

- Check for the presence and text of the error message when invalid files are uploaded.
- Verify that a valid image uploads successfully without errors.

---

## Automation notes

- Files are generated in-memory as buffers (`utils/images.ts`) with the required MIME type
  and size, so no large binary fixtures need to be committed to the repository.
- The "Add Image" field is an `app-drag-and-drop` component:
  - **Rejected file** → the dropzone gets the `warning-background` class with a red border
    `rgb(235, 24, 13)`, and the warning message gets the `warning-color` class (red text).
  - **Accepted file** → the dropzone is removed from the DOM and replaced by the image cropper.
- The phrase "Upload only PNG or JPG. File size must be less than 10MB" is always present as a
  static hint; the **red** state (classes above) is what distinguishes an actual error.
- Invalid files are uploaded first (they keep the file input), and the valid PNG is uploaded
  last (it opens the cropper and removes the input).

### Detected product bug — wrong error message wording

The actual validation message does not match the specification:

| Expected (spec) | Actual (UI) |
| --- | --- |
| `Upload only PNG or JPEG. File size must be less than 10MB.` | `Upload only PNG or JPG. File size must be less than 10MB` |

Differences: **"JPG" instead of "JPEG"** and a **missing trailing period**.
The test asserts the exact specified text, so it **fails by design**, flagging this bug.
All functional checks (red highlight for invalid files, successful upload of a valid PNG) pass.
