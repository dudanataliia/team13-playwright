# TC-06 — Source field validation (optional, valid URL)

**Description:** Verify the validation of the "Source" field (optional, must be a valid URL).

**Preconditions:**

- The user is logged into the system.
- The "Create News" form is open.

**Steps:**

1. Navigate to [GreenCity News](https://www.greencity.cx.ua/#/greenCity/news) and click "Create News".
2. Leave the "Source" field empty.
3. Fill in all mandatory fields and click "Publish".
4. Verify that the news is published successfully without errors.

5. Enter an invalid URL in the "Source" field (e.g., "www.example.com").
6. Verify that:

- The "Publish" button remains disabled.
- An error message appears in red:
- "Please add the link of the original article/news/post. The link must start with http(s)://".

7. Enter a valid URL in the "Source" field (e.g., "https://example.com").
8. Verify that:

- The error message disappears.
- The "Publish" button becomes enabled.
- Click "Publish".
- Verify that the news is published successfully with the provided source link.

**Expected Result:**

- An empty "Source" field is allowed.
- An invalid URL triggers an error message in red, and the "Publish" button remains disabled.
- A valid URL is accepted, and the "Publish" button becomes enabled.

**Automated Verification:**

- Check if the error message appears for an invalid URL.
- Verify that the "Publish" button remains disabled until a valid URL is entered.
- Confirm that news is published successfully with a valid source.

---

## Automation notes

- All mandatory fields (Title, tag, Main Text) are filled first, so "Source" is the only variable.
- Indicators:
  - **Invalid URL** → the `input[formcontrolname="source"]` gets the `field-warning` class and the
    hint message gets the `warning` class (red, `rgb(235, 24, 13)`); "Publish" is disabled.
  - **Empty / valid URL** → no `field-warning`, the message is grey, and "Publish" is enabled.

### Functional behaviour confirmed (passes)

- Empty Source → "Publish" enabled (optional field).
- Invalid URL `www.example.com` → red error + "Publish" disabled.
- Valid URL `https://example.com` → error cleared + "Publish" enabled + news published successfully.

### Detected product bugs (test fails by design)

**1. Wrong error message wording**

| Expected (spec) | Actual (UI) |
| --- | --- |
| `Please add the link of the original article/news/post. The link must start with http(s)://` | `Please add the link of original article/news/post. Link must start with http(s)://` |

Missing **"the"** before "original article" and **"The"** before "link must start".

**2. Source link is not saved / not displayed on the published news**

When a news item is published with a valid Source URL (e.g. `https://example.com/...`), opening
the published news shows **no source link at all** — the `.source-text` element is empty and the
URL is not present anywhere on the detail page (`#/greenCity/news/<id>`). This contradicts the
step "the news is published successfully **with the provided source link**".
