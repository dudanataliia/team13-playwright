# TC-09 — "Edit news" button visible to the author

**Description:**
Verify that only the author of the news can see the "Edit news" button.

**Preconditions:**

- User is logged in.
- User has previously created a news post.

**Steps:**

- Log in as the user who created the news.
- Navigate to the news post.
- Check for the presence of the "Edit news" button.

**Expected Result:**

- The "Edit news" button is visible to the author.
- Automated Verification:
- Assert that the "Edit news" button is displayed on the page.

---

## Automation notes

- The test creates a fresh news post as a precondition (logged-in user via the `loginAsUser`
  fixture), then opens that post and asserts the "Edit news" control is visible.
- The "Edit news" control is a `<div class="edit-news">` ("Edit news") wrapped in an `<a>`.
  Locator: `.edit-news`. The author also sees a `.delete-news-button` ("Delete").
- News cards on the list are wrapped in `<a href="#/greenCity/news/{id}">`. After publishing,
  a transient `cdk-overlay-backdrop` can intercept a card click, so `openNewsByTitle` reads the
  wrapping anchor's `href` and navigates directly to the post — this is more stable.

## Result: PASS

- The "Edit news" button is displayed on the author's own news post as expected.
